# PassGo

Учебный проект по проектному практикуму — веб-приложение для управления мероприятиями, регистрации участников и учёта фактического посещения по QR-билетам.

## Цель

Объединить подготовку мероприятия, выдачу билетов, проверку участников на входе и получение статистики в одном приложении.

## Возможности MVP

- Создание, редактирование, публикация и отмена мероприятий.
- Управление площадками, помещениями и программой.
- Регистрация участников с ограничением количества мест.
- Электронные билеты с QR-кодом.
- Проверка билетов камерой телефона или ручным вводом кода.
- Учёт посещений с защитой от повторного входа.
- Статистика регистраций и уникальных посещений, экспорт CSV.

Первая версия рассчитана на бесплатные мероприятия. Для проверки билетов требуется интернет. Оплата, выбор мест, офлайн-проверка, SMS и учёт посещения отдельных секций не входят в MVP. PDF-билеты, email и установка PWA — необязательные расширения.

## Пользователи

- **Гость** — просмотр опубликованных мероприятий и программы.
- **Участник** — регистрация и доступ к собственным билетам.
- **Организатор** — управление своими мероприятиями, программой, сотрудниками и статистикой.
- **Сотрудник входа** — проверка билетов назначенного мероприятия.

## Совместная работа

Для каждой задачи создавать отдельную ветку, например `feature/s1-08-backend-bootstrap`. В названии изменения указывать код задачи. Перед объединением проводить проверку вторым разработчиком. Секреты, пароли, реальные билеты и личные данные не добавлять в репозиторий.
