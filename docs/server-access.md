# Доступ к серверу

Сервер PassGo создан в Яндекс Cloud. Статический IP: 51.250.38.112. Имя пользователя: passgo.

Подключение из PowerShell:

```powershell
ssh -i "$env:USERPROFILE\.ssh\passgo_yandex_ed25519" passgo@51.250.38.112
```

Закрытый ключ хранится на компьютере в папке .ssh. Его нельзя добавлять в Git или отправлять другим людям. В облако добавлена только открытая часть ключа.

Файлы приложения находятся в /opt/passgo. Команды Docker на сервере выполняются через sudo.

Проверить контейнеры: `cd /opt/passgo && sudo docker compose -f compose.production.yml ps`.

Посмотреть последние сообщения: `sudo docker compose -f compose.production.yml logs --tail 30`.

Окружение создаётся отдельно на сервере. Локальные пароли туда не копируются. Для обычного просмотра настроек не нужно выводить содержимое .env.production.

Статический адрес сохраняется при остановке ВМ, но продолжает оплачиваться. Диски также сохраняются и оплачиваются. После окончания работы над проектом нужно отдельно решить, какие ресурсы оставить.
