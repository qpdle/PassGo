# Разработка PassGo

Даниил ведёт сервер, базу и развёртывание. Максим делает интерфейс, запросы к серверу и сканер. Требования и инструкции хранятся в docs, документы Word — в общей папке PassGo.

Используются Python 3.12, Django 5.2, PostgreSQL 17 и Node.js 22 начиная с 22.12.0. Версии библиотек закреплены в requirements и package-lock.json. Интерфейс устанавливается командой npm ci.

Для локального запуска нужен корневой .env по примеру .env.example. Ключ Django и пароль базы задаются отдельно и не попадают в Git. Команда docker compose up --build -d запускает сервер и базу. Интерфейс запускается из папки frontend командой npm run dev.

main содержит объединённые изменения. Для спринта используется отдельная ветка, например feature/s2-events. В коммитах указываем код задачи и коротко пишем, что изменилось.

Чек-листы отмечаем по фактическому результату. Для серверных изменений проверяем тесты и миграции, для интерфейса — типы, сборку и основные сценарии в браузере. Команды находятся в checks.md.

В Git не добавляем пароли, файлы окружения, закрытые ключи, базу и данные настоящих участников. Ссылки на код и результаты добавляем в карточки задач.
