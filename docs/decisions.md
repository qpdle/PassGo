# Решения первого спринта

React и TypeScript выбраны для интерфейса. Они подходят для страниц организатора, участника и сканера. Vite нужен для локального запуска и сборки. Tailwind используется для оформления, React Router — для переходов между страницами.

Django и Django REST Framework выбраны для сервера. Django предоставляет пользователей, пароли, миграции и административный интерфейс. Собственная модель пользователя позволяет входить по email.

PostgreSQL хранит данные и проверяет ограничения. Регистрация, билет и посещение будут отдельными объектами.

Docker Compose используется для одинакового запуска сервера и базы. На общем стенде Gunicorn запускает Django, Caddy отдаёт интерфейс и API через HTTPS.

TanStack Query управляет загрузкой ответов и повтором запросов. html5-qrcode используется в техническом сканере. Сканер пока не создаёт посещения.

Для стенда выбрали Яндекс Cloud. Для стенда используется стартовый грант. IP закреплён. Бесплатное имя sslip.io позволяет проверить HTTPS без покупки домена.

После публикации изменений нужно проверить GitHub Actions и запуск проекта по инструкции. Найденные ошибки записываем в задачи.
