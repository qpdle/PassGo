# Backend PassGo

Планируемая серверная часть: Django, Django REST Framework и PostgreSQL.

Каркас и подключение базы создаются в S1-08, начальные модели и миграции — в S1-09. Инструкция запуска появится после проверки рабочего каркаса.

Python 3.12. Основные зависимости закреплены в requirements.txt, инструменты разработки — в requirements-dev.txt. Разрешение серверных зависимостей проверено без установки. Файлов manage.py, настроек Django и миграций пока нет.
