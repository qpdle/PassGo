# Прототип экранов PassGo — S1-10

Откройте `index.html` в браузере. Установка зависимостей и сервер не нужны.

Макет включает девять экранов для участника, организатора и сотрудника. Навигация слева на компьютере и горизонтально на телефоне. Нижний переключатель показывает варианты ошибок и пустых состояний как примеры сообщений; он не имитирует отказ сервера и не блокирует формы.

Демонстрационные сценарии:

1. Мероприятие → регистрация → заполнить форму → билет → мои регистрации.
2. Сканер: после регистрации ввести `PASSGO-DEMO`. Повторить проверку: повторное посещение не подтверждается.
3. Мои регистрации → отмена → билет становится примером; сканер отклоняет проход.
4. Редактор: окончание раньше начала отклоняется. Сохранение черновика и публикация меняют состояние примера.
5. Программа: добавить зал и выступление. Пересечения времени в одном зале отклоняются; соседние интервалы и параллельные выступления в разных залах допускаются.
6. Статистика → скачать пример CSV.

Данные живут в памяти вкладки и сбрасываются при перезагрузке. QR — подписанное место для изображения, камера не подключена. Авторизация, серверные права, билеты, письма и фактическая статистика будут реализованы отдельно. Числа статистики фиксированы и не связаны со сканером.

Для макета нужны проверка в браузере при ширине 360 px и соответствие контракту API. Макет не заменяет реализацию приложения S1-11.
