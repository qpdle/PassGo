# Frontend PassGo

Планируемый интерфейс: React, Vite, TypeScript и Tailwind CSS.

Каркас создаётся в S1-11; сквозной запрос к серверу — в S1-12; эксперимент со сканером на телефоне — в S1-15.

Node.js 22 начиная с 22.12.0. Начальные зависимости закреплены в package.json. Команды dev, build и проверки типов добавляются с исходниками в S1-11; пока package.json задаёт только список библиотек. Там же создаётся package-lock.json. Пример публичного адреса API находится в .env.example.
