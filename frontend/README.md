# Интерфейс PassGo

Для запуска нужен Node.js 22.12 или новее.

1. Запустить Docker Desktop и выполнить `docker compose up --build -d` в корне проекта.
2. В папке frontend выполнить `npm ci`, затем `npm run dev`.
3. Открыть http://127.0.0.1:5173.

Работают создание аккаунта, вход и выход, кабинет организатора, редактор мероприятия, площадки и помещения, программа, назначение сотрудников и публикация. Гостю доступны каталог и страница опубликованного мероприятия. Данные берутся из Django и сохраняются в PostgreSQL.

При создании мероприятия форма пустая. Сначала нужно сохранить черновик, затем выбрать помещения и добавить программу. После выбора площадки выберите помещение. Оно сохраняется автоматически и сразу становится доступно в программе. При ошибке можно повторить сохранение. Публикация проверяет вместимость. После публикации даты и состав помещений не меняются. Время в формах относится к часовому поясу мероприятия, а не компьютера.

API доступен через /api/v1. В локальной работе Vite пересылает запросы на http://127.0.0.1:18000. Другой адрес задаётся через API_PROXY_TARGET в локальном файле окружения. Django должен разрешать адрес интерфейса в DJANGO_CSRF_TRUSTED_ORIGINS; примеры уже содержат localhost и 127.0.0.1.

Сборка: `npm run build`. Проверка TypeScript: `npm run typecheck`. Тесты преобразования времени: `npm test`.

Пароль и сессия не сохраняются приложением в localStorage. После выхода данные прежнего аккаунта удаляются из памяти запросов. При сетевой ошибке форма сохраняет введённые значения и позволяет повторить действие.
