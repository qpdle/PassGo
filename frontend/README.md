# Интерфейс PassGo

Для запуска нужен Node.js 22.12 или новее.

1. Запустить Docker Desktop и выполнить `docker compose up --build -d` в корне проекта.
2. Открыть папку frontend в терминале.
3. Выполнить `npm ci`.
4. Выполнить `npm run dev`.
5. Открыть http://127.0.0.1:5173.

Сборка: `npm run build`. Проверка TypeScript: `npm run typecheck`.

Интерфейс обращается к серверу через /api/v1. Vite пересылает эти запросы на http://127.0.0.1:18000. Другой адрес задаётся в локальном .env через API_PROXY_TARGET. Пример настроек находится в .env.example. Пароли и ключи в настройки интерфейса не добавляются.

Сейчас работают меню, страницы-заготовки, страница неизвестного адреса, проверка связи и загрузка тестового списка мероприятий. При ошибке можно повторить запрос. Страница списка показывает ответ сервера, а не встроенный массив клиента.

Маршрут /api/v1/demo/events/ возвращает вымышленные данные и доступен только при DEBUG=true. Это отдельная проверка соединения, а не рабочий каталог. Регистрация, билеты, редактор и сканер подключаются в следующих задачах.

Чтобы проверить ошибку сети, остановить backend, открыть страницу связи и нажать «Проверить ещё раз». После запуска backend повторить проверку.

Экран проверки билетов содержит технический прототип камеры и ручной ввод. Он только читает код и не создаёт посещение. Для камеры нужен HTTPS или localhost. Проверка реальных телефонов пока не проведена.
