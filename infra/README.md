# Инфраструктура PassGo

Локальный Docker Compose находится в корне репозитория: docker-compose.yml. Инструкция запуска — backend/README.md. В S1-08 используются контейнеры Django и PostgreSQL с постоянным томом.

Общий HTTPS стенд и производственная конфигурация относятся к S1-14. Сертификаты, ключи, .env и данные базы не включаются в Git.
